# Changelog

## 1.0.0 — 2026-10-20

First public release.

- Web component, `data-*` attributes and JS / JSON APIs with one set of options.
- 27 CSS and 13 WebGL transitions, loop without cloned slides, drag on every effect.
- Smart fit (focal point, safe area, blurred backdrop), `height: "image"`, zero-config responsive height and `minSlideWidth`.
- Layer engine with 22 text and 8 image recipes and custom recipes.
- Overlays, particles, scroll depth, scroll-driven sliders, thumbnails, deep links.
- English and Turkish labels; full accessibility support.
